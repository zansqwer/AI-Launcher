## 使用说明 (How to Use)

打开后:

1. 按 **CMD+K** (Mac) 或 **Ctrl+K** (Windows) 来打开启动器
2. 输入任何命令或问题
3. 点击快捷操作卡片
4. 按 **Enter** 提交
5. 按 **Esc** 关闭

## 功能特性

- ✨ 现代玻璃态设计
- ⚡ 快速命令面板
- 🤖 AI 聊天界面  
- 📝 最近命令历史
- ⌨️ 键盘快捷键支持
- 📱 响应式设计

## 故障排除

**无法打开启动器？**
- 打开浏览器控制台 (F12 或 CMD+Option+I)
- 按 CMD+K
- 查看是否有错误信息

**测试键盘检测:**
打开 `keyboard-test.html` 查看键盘事件是否正常工作
